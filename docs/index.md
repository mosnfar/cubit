Quell is a live chat moderation demo with an API, viewer interface, moderation workflow, and evaluation tools. These guides describe the current implementation and its operating requirements.

- [API reference](api-reference.md): routes, request and response shapes, server-sent events, and limits.
- [Operations](operations.md): setup, configuration, persistence, backups, reset, and recovery.
- [Data handling and privacy](data-handling.md): local storage, external requests, recording behavior, and deletion limits.
- [Documentation site](docs-site.md): how to run, build, preview, and publish this documentation.
